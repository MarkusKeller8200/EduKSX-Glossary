# Confluence-Publisher – spätere Projektphase

**Beschlossen:** Confluence ist Datenempfänger, nicht Datenbasis. Freigegebene Glossarbegriffe können als Confluence-Seiten in beliebigen berechtigten Spaces veröffentlicht werden.

**Vorschlag:** Pro Ziel Site/Space/Elternseite und Filter speichern, Seiteninhalte aus Publikationsrelease rendern, Seiten-ID/Versionsnummer festhalten, bei Änderungen sicher aktualisieren, Konflikte und Löschungen behandeln, Retry und Audit vorsehen. Mehrere Sites/Spaces unterstützen. Die Integration kann unabhängig von MCP betrieben werden.

**Offen:** Format, Seitenaufteilung, Freigaberechte, Konfliktbehandlung, historisierte Confluence-Seiten und gewünschte Synchronisationsfrequenz.
